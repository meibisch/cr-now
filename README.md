# Chasing Reverbs – Now

One song for the hour you are in. Static page at https://now.chasingreverbs.com

Reads the visitor's local time, weekday and date and shows exactly one track
from the catalogue: black-and-white cover, title, clock, Spotify player. When a
song ends, the page goes dark for 45 seconds. *This is the sound before the silence.*

No backend, no database, no API key at runtime. The only external resource is
Spotify's embed script.

## Adding a new release

The hour profiles and the build step live outside this repo (same pattern as
the Timeline helpers):

```
/Volumes/T7/Chasing Reverbs/Data and Analytics/Chasing Reverbs Now/build/
├── curation.py     ← one line per track: hour anchor, season, weekday, accent
├── build.py        ← writes data/tracks.js, covers/*.jpg, og.jpg
├── catalog.json    ← Spotify catalogue snapshot (refreshed with --fetch)
└── _raw/           ← cached original artwork from Spotify
```

1. Add the new track to `curation.py` (a track without an entry is placed
   neutrally at noon and reported by the build).
2. Run the build with the Timeline project's virtualenv (it holds the Spotify
   credentials in its `.env`; build-time only):
   ```bash
   cd "/Volumes/T7/Chasing Reverbs/Data and Analytics/Chasing Reverbs Now/build"
   "../../Chasing Reverbs Timeline/.venv/bin/python" build.py --fetch
   ```
3. Commit and push, then deploy from a clean copy (the T7 is exFAT and
   litters `._*` resource-fork files that wrangler would otherwise upload):
   ```bash
   rsync -a --delete --exclude '._*' --exclude '.git' "/Volumes/T7/Chasing Reverbs/Website/Now/" /tmp/cr-now-deploy/
   source ~/.cloudflare-cr.env
   wrangler pages deploy /tmp/cr-now-deploy --project-name cr-now --branch main
   ```

## How the hour is chosen

Every track has an hour anchor and a width (a Gaussian on the 24-hour clock).
`dawn`/`dusk` anchors move with the season (approximated for 50° N).
Seasonal pieces (December, June, autumn, the days between the years) are
boosted in their window and practically never shown outside it. Weekend and
weekday pieces get a mild nudge. A deterministic per-hour seed picks from the
top candidates, so a refresh within the same hour shows the same song and the
next day shows a neighbour. `another` cycles through the eight closest matches.

*Out of the Blue* is the only title that may carry the accent colour `#5b7fa6`.

## File structure

```
cr-now/
├── index.html      ← Shell
├── now.css         ← Styles (text contrast per Style Guide v1.1 §2)
├── now.js          ← Scoring, clock, Spotify iFrame API, silence
├── CNAME           ← Custom domain
├── favicon.png     ← Shared Chasing Reverbs favicon
├── og.jpg          ← Social preview (generated by the build, no AI image)
├── data/
│   └── tracks.js   ← Generated: one entry per track with its hour profile
├── covers/
│   └── <slug>.jpg  ← Generated: grayscale, 1000 px, film grain baked in
└── fonts/
    └── Broadway-Regular.woff2
```
